# F-004 — ponowny test ładowania pulpitu menedżera

- Data: 2026-10-16.
- Ustalenie: [F-004](../findings.md#f-004--niepełny-stan-ładowania-pulpitu-menedżera-po-odświeżeniu).
- Powiązany scenariusz: [COM-01](../scenarios/common.md).
- Środowisko wskazane w instrukcji: lokalna aplikacja `http://localhost:3000` w Chrome.
- Konto wskazane w instrukcji: menedżer `manager001@post.pl`, szkoła „OSK Warszawa Demo 1”.
- Zakres instrukcji: odświeżyć pulpit przy spowolnionym połączeniu na szerokim i wąskim ekranie; sprawdzić pełny szkielet karty szkoły, skrótów, spraw wymagających uwagi i wolnych terminów oraz jego zniknięcie po pobraniu danych.
- Wynik ręczny: użytkownik potwierdził, że szkielet działa poprawnie. Następnie poprosił o usunięcie widocznego napisu „Ładowanie danych pulpitu…” i po tej zmianie polecił zamknąć punkt.
- Weryfikacja poprawki napisu: test UI szkieletu przeszedł; Prettier, ESLint i `git diff --check` nie zgłosiły błędów.
- Ograniczenie zapisu: użytkownik nie przekazał osobnego opisu każdego kroku ani nowego przebiegu ręcznego po usunięciu napisu.

Ustalenie F-004 zamknięto na podstawie potwierdzenia użytkownika i jego polecenia.
