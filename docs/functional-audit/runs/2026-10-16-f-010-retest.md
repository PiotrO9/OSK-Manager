# F-010 — ponowny test komunikatu niepotwierdzonego e-maila

- Data: 2026-10-16.
- Ustalenie: [F-010](../findings.md#f-010--mylący-komunikat-przy-logowaniu-bez-potwierdzonego-e-maila).
- Powiązane scenariusze: [MGR-INS-01](../scenarios/manager.md) i [COM-01](../scenarios/common.md).
- Środowisko wskazane w ustaleniu: lokalna aplikacja `http://localhost:3000`.
- Zakres ustalenia: próba logowania kontem z niepotwierdzonym adresem powinna pokazać „Potwierdź adres e-mail, aby się zalogować.”; błędne hasło powinno nadal wyświetlać neutralny komunikat o niepoprawnych danych.
- Wynik ręczny: użytkownik polecił oznaczyć F-010 jako zaliczony. Nie przekazał osobnego zapisu obserwacji poszczególnych prób ani danych użytego konta.

Ustalenie F-010 zamknięto na podstawie potwierdzenia użytkownika.
