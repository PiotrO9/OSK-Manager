# Wymagania objęte audytem

Wymaganie opisuje oczekiwany rezultat użytkownika. Status `potwierdzone` oznacza,
że zachowanie ma źródło w obecnym interfejsie, API lub dokumentacji i może być
ocenione podczas audytu; nie dowodzi jeszcze, że działa. `Do decyzji` oznacza,
że oczekiwany wynik wymaga decyzji właściciela produktu. `Planowane` nie jest
częścią bieżącego odbioru. Identyfikatory są stałe.

Scenariusze powiązane z wymaganiem zawierają odnośniki do konkretnych ekranów,
usług i testów, na których oparto inwentaryzację. Status `potwierdzone` dotyczy
definicji oczekiwania, a nie wyniku testu ani jakości implementacji.
