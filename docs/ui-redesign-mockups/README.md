# UI Redesign Mockups

Ten folder zawiera zaakceptowane mockupy PNG dla redesignu OSK Managera.

Kazdy widok ma dwa pliki:

- `*-desktop.png`
- `*-mobile.png`

Mockupy sa wzorcem UI: layoutu, spacingu, hierarchii, gestosci informacji, stylu paneli, tabel, formularzy i kalendarzy.

Mockupy nie sa zrodlem prawdy o danych ani funkcjach. Podczas implementacji nie dodawaj fikcyjnych sekcji, statystyk, filtrow, statusow ani akcji tylko dlatego, ze sa widoczne na PNG.

Jezeli mockup pokazuje cos, czego nie ma w aktualnym widoku, API albo komponencie, zapisz to w `../UI_REDESIGN_IMPLEMENTATION_TODO.md` w kolumnie `Braki / decyzje` i nie renderuj tego na stronie.
